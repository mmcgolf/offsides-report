Methodology

True probabilities are derived from sharp reference books (Pinnacle, LowVig, BetOnline) using the power method for vig removal. When sharp books are unavailable, consensus is built from NC-legal books weighted by inverse overround.

EV thresholds are time-adjusted: the minimum edge equals 2% plus the annualized risk-free rate (4.5%) prorated to the lockup period. Position sizing uses quarter-Kelly criterion.

NC-legal books only. Sharp reference books are used for consensus pricing, not as betting recommendations. Not financial advice. Gamble responsibly.
